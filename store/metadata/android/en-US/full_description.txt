BULBVPN is a private OpenVPN client built for everyday Wi-Fi and mobile data, including networks in Iran where ordinary tunnels stall. No account. No subscription. No ads. No activity log uploaded from your phone.

OPEN VPN FIRST
The app prefers OpenVPN and tries a working profile before it gives up. On networks that complete a handshake and then drop the payload, it moves on to the next reachable endpoint instead of sitting on one dead server.

ONE SCREEN
Your exit IP is on the home screen — tap to copy it. Session time and transfer rates update while you are connected. A session log stays on the device so you can see what the tunnel did.

WHAT YOU GET
• Private tunnel on Wi-Fi and mobile data
• OpenVPN, the audited protocol the app connects with first
• No account — install and tap connect
• Exit IP on screen, with country, so you can check it yourself
• On-device session log — connection events are not uploaded
• Server list you can pick from, or let the app try the next reachable one
• Built-in speed test: download, upload, ping, packet loss, and jitter through the tunnel
• Dark interface with live status

HOW IT WORKS
1. Open the app. Your current public IP is shown.
2. Tap connect. BULBVPN sets up the VPN profile, then brings up OpenVPN.
3. Watch the exit IP change when the tunnel is up.
4. Run the speed test when you want a measurement from this session.

PRIVACY
BULBVPN does not require an account and does not keep a browsing history. Server lists come from a public mirror. Read the in-app privacy policy before you connect.
